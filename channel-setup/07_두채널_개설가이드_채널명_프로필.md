## 1. 계정 구조 (먼저 정하고 시작)

```
채널① 간 큰 남편                     채널② 인테리어
 └ Gmail A (채널 전용)                  └ Gmail B (채널 전용)
    ├ 유튜브: 브랜드 계정                    ├ 유튜브: 브랜드 계정
    ├ 인스타: 크리에이터 계정                ├ 인스타: 크리에이터 계정
    │   └ 스레드 (인스타로 로그인)           │   └ 스레드 (인스타로 로그인)
    └ 틱톡: 이메일 가입                      └ 틱톡: 이메일 가입
```

- **채널마다 이메일을 따로** 쓰는 이유: 나중에 한 채널만 팔거나, 편집자·대행사에게 넘기거나, 정지 같은 문제가 생겨도 다른 채널이 같이 묶이지 않아요.
- **휴대폰 번호는 정준님 번호 하나로 OK.** 대신 모든 계정에 **2단계 인증** 꼭 켜기(해킹되면 채널 복구가 정말 어려워요).
- 비밀번호는 휴대폰 비밀번호 관리자(구글 비밀번호 관리자 / iCloud 키체인)에 저장.
- **유튜브는 "브랜드 계정"으로**: 정준님 개인 구글 계정 이름이 채널에 안 나오고, 나중에 관리자(편집자)를 추가할 수 있어요.
- 휴대폰 앱 하나에 계정 여러 개 로그인 가능: 인스타는 "계정 추가"로 최대 5개, 틱톡도 "계정 추가"로 전환해서 쓰면 돼요.

## 2. 플랫폼별 개설 단계

### 2-0. 핸들(@아이디) 비어 있는지 확인하는 법 (1분)

> ⚠️ 이 클라우드 환경에서는 외부 사이트 접속이 막혀 있어 **핸들 중복 확인을 직접 하지 못했어요.** 아래 방법으로 1분이면 확인됩니다.

휴대폰/PC 주소창에 핸들을 넣어서 열어 보세요. **"페이지를 찾을 수 없음 / 사용할 수 없는 페이지"가 나오면 비어 있는 것**(정확한 건 가입할 때 입력해서 초록 체크가 뜨는지로 최종 확인).

| 플랫폼 | 확인 주소 (예: gankeun_hubby) |
|---|---|
| 유튜브 | `youtube.com/@gankeun_hubby` |
| 인스타 | `instagram.com/gankeun_hubby` |
| 스레드 | `threads.com/@gankeun_hubby` |
| 틱톡 | `tiktok.com/@gankeun_hubby` |

- 핸들은 **영문 소문자 + 숫자 + 밑줄(_)** 만 쓰세요. 점(.)·하이픈(-)은 플랫폼마다 허용이 달라서 4곳 통일이 깨져요.
- 틱톡 아이디는 **24자까지**라 모든 후보를 20자 안으로 맞춰 뒀어요.
- 한 곳이라도 이미 있으면 → 표에 적어 둔 **예비 핸들**로 바꿔서 4곳 모두 같은 걸로.

### 2-1. 유튜브 (채널마다 반복)

**만들기**
1. 크롬에서 채널 전용 Gmail로 로그인 → `youtube.com` → 오른쪽 위 프로필 → **채널 만들기**
2. **"맞춤 이름을 사용하세요"** 쪽을 선택 → 채널 이름 입력 (이게 브랜드 계정으로 만들어지는 방법)
3. 핸들 입력란에 `@핸들` 입력 → 초록 체크 확인 → 만들기
4. **유튜브 스튜디오** (`studio.youtube.com`) → 설정 → 채널 → 국가 **대한민국**, 키워드 입력
5. 설정 → 채널 → **고급 설정** → "아동용으로 설정 안 함" 선택 (두 채널 다 성인 대상)
6. 휴대폰 인증: `youtube.com/verify` → 인증하면 **15분 넘는 영상, 맞춤 썸네일, 링크** 기능이 열려요.

**맞춤설정 (스튜디오 → 맞춤설정)**
| 항목 | 규격 | 이번 시안 |
|---|---|---|
| 프로필 사진 | 800×800px 이상, 원형으로 잘림, 4MB 이하 | 3번 표 "프로필" 이미지 |
| 배너 | 2048×1152px 이상, 6MB 이하. **가운데 1235×338px만 모든 기기에서 보임** | 3번 표 "배너" 이미지 (가운데를 비워 둠) |
| 소개(설명) | 1,000자 | 3번 표 소개글 |
| 링크 | 여러 개 가능, 첫 번째 링크가 채널 상단에 보임 | 쿠팡 링크 모음 페이지 1개 (아래 2-6) |

> 배너 시안은 1344×752로 뽑았어요. 확정하면 **업스케일(고해상도 변환)** 후 2048×1152 이상으로 올리고, 채널 이름(한글)은 캔바·미리캔버스에서 가운데 띠에 얹으면 돼요(한글은 편집 합성 원칙).

**수익화 (유튜브 파트너 프로그램, YPP)** — 조건은 스튜디오 → **수익 창출** 메뉴에서 현재 기준 확인
- 1단계(팬 후원·쇼핑 일부): 구독자 500명 + 최근 90일 업로드 3개 + (최근 12개월 시청 3,000시간 **또는** 최근 90일 쇼츠 조회 300만)
- 2단계(광고 수익): 구독자 1,000명 + (최근 12개월 시청 4,000시간 **또는** 최근 90일 쇼츠 조회 1,000만)
- 신청 시 **애드센스 계정** 연결(채널마다 따로 만들지 말고, 정준님 명의 애드센스 1개에 두 채널 연결 가능)

**쇼츠에서 제휴 링크는 이렇게**
- 쇼츠 설명란·댓글의 링크는 **눌리지 않아요.** 그래서:
  1. **채널 상단 링크**에 "링크 모음" 1개 걸기 → 영상에서 "채널 프로필 링크에 있어요"라고 안내
  2. 구독자가 늘면 **유튜브 쇼핑 제휴**(쿠팡 상품 태그) 신청 가능해지는지 스튜디오 → 수익 창출 → 쇼핑에서 확인
  3. 같은 내용의 **긴 영상**을 가끔 올리면 그 설명란 링크는 눌려요

### 2-2. 인스타그램 (채널마다 반복)

**만들기**
1. 인스타 앱 → 내 프로필 → 맨 위 아이디 누르기 → **계정 추가** → **새 계정 만들기**
2. 채널 전용 Gmail로 가입 → 아이디에 핸들 입력
3. 설정 → **계정 유형 및 도구** → **프로페셔널 계정으로 전환** → **크리에이터** 선택
   - 카테고리: ① **"디지털 크리에이터"** 또는 "건강/뷰티" ② **"디지털 크리에이터"** 또는 "인테리어 디자인"
   - "비즈니스"가 아니라 **크리에이터**를 고르는 이유: 음악 선택 폭이 넓고, 제휴·브랜디드 콘텐츠 도구가 크리에이터 중심이에요.
4. 프로필 편집
   - **이름** 칸은 검색에 걸려요 → `채널명 | 검색 키워드` 형태로 (3번 표 참고, 최대 64자)
   - **소개** 150자 / **링크** 최대 5개 (첫 칸에 쿠팡 링크 모음)
   - 프로필 사진: 320×320px 이상, 원형
5. 설정 → **크리에이터 도구 및 관리** → 브랜디드 콘텐츠 → "유료 파트너십 표시" 켜기 준비

**광고 표기 (제휴 링크가 들어간 게시물)**
- 캡션 **첫 줄 맨 앞**에 `[광고]` 또는 `[쿠팡 파트너스 활동]` 같이 명확하게. 해시태그 속에 숨기면 공정위 기준(추천·보증 심사지침) 위반이에요.
- 캡션에 쿠팡 문구: "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- 협찬(브랜드에서 물건·돈을 받은 경우)은 **유료 파트너십 라벨**까지 켜기.

### 2-3. 스레드 (인스타 다음에 바로)

1. 스레드 앱 설치 → **"인스타그램으로 계속"** → 방금 만든 채널 인스타 계정 선택
2. 아이디는 **인스타 핸들이 그대로** 따라와요(그래서 인스타 핸들을 먼저 잘 잡는 게 중요).
3. 프로필 가져오기 → 소개글만 스레드용으로 바꾸기(3번 표, 150자)
4. 링크: 프로필에 링크 추가 가능 (쿠팡 링크 모음 1개)
5. 게시물에 제휴 링크를 넣을 땐 인스타와 똑같이 **첫 줄에 [광고]**.

> 💡 스레드는 영상보다 **글**이 먹혀요. 채널①은 "오늘의 작전 일지"(들킬 뻔한 썰), 채널②는 "만원으로 바꾼 것 3가지" 같은 짧은 글 + 사진 1장이 잘 맞아요.

### 2-4. 틱톡 (채널마다 반복)

**만들기**
1. 틱톡 앱 → 프로필 → 오른쪽 위 ≡ → 설정 → **계정 전환 → 계정 추가 → 가입** → **이메일**로 (채널 전용 Gmail)
2. 생년월일 입력 → **아이디**(핸들) 설정
3. 프로필 편집: 이름(30자) / 아이디 / 소개 **80자** / 프로필 사진 200×200px 이상
4. 설정 → 계정 → **비즈니스 계정으로 전환은 하지 말기**(개인 계정 유지)
   - 비즈니스 계정은 **유행하는 음원 대부분을 못 써요**(상업용 음원만). 숏폼에서 음원 손해가 커요.

**알아둘 것**
- 아이디는 **30일에 한 번**, 이름은 **7일에 한 번**만 바꿀 수 있어요 → 처음에 신중하게.
- 프로필 **웹사이트 링크**는 개인 계정의 경우 팔로워 조건(보통 1,000명)이 있어요. 그 전까지는 소개글에 "유튜브·인스타에 링크 있어요"로 안내.
- 틱톡샵은 한국에서 아직 운영되지 않아(2026년 11월 기준 앱에서 확인 필요) 틱톡은 **노출·팔로워 모으기용**, 제휴 전환은 유튜브·인스타 링크로 넘기는 구조로 가요.
- 업로드할 때 **"콘텐츠 공개"(브랜드 콘텐츠/광고 표시)** 토글을 제휴 영상에 켜기.

### 2-5. 첫 영상 올리기 전 필수 설정 (두 채널 공통)

| 항목 | 유튜브 | 인스타·스레드 | 틱톡 |
|---|---|---|---|
| 제휴·광고 표시 | 업로드 → 세부정보 → **"유료 프로모션 포함"** 체크 | 캡션 첫 줄 **[광고]** + 협찬이면 유료 파트너십 라벨 | **콘텐츠 공개** 토글 |
| AI 생성 표시 | 업로드 → **"변경되거나 합성된 콘텐츠"** = 예 (사실처럼 보이는 AI 영상·이미지일 때) | 게시 → 고급 설정 → **AI 정보** 라벨 | 업로드 → 더보기 → **AI 생성 콘텐츠** 표시 |
| 쿠팡 문구 | 설명란 | 캡션 | 캡션 |

- **채널②(인테리어)는 힉스필드 이미지·영상을 쓰니까 AI 표시를 매번 켜요.** 안 켰다가 플랫폼이 감지하면 노출이 줄거나 경고가 와요. 켜도 조회수 손해는 크지 않아요.
- **채널①(간 큰 남편)은 실제 촬영**이라 AI 표시는 필요 없음. 대신 피부 시즌엔 **화장품법**: "주름 개선·미백·재생" 같은 효능 단정 말 금지, 전후 비교 화면으로만 보여 주기.
- 유튜브는 **"대량 생산·반복 콘텐츠"** 를 수익화에서 막아요. 채널②가 자동화여도 ① 정준님 목소리(클론) ② 대본 3문장 내 말로 + "직접 해보니" 1문장 ③ 매 편 다른 상품·다른 공간 — 이 3개가 지켜지면 안전해요(06 구성안과 같은 원칙).

### 2-6. 링크 모음 페이지 (두 채널 각각 1개)

- 쇼츠·틱톡에서는 링크가 잘 안 눌리니까, 모든 플랫폼 프로필에 **같은 링크 모음 1개**를 걸어요.
- 무료 도구: **인포크링크(inpock)** 또는 **링크트리** → 영상 번호별로 "#12 현관 넓어 보이는 매트" 식으로 상품 링크 정리.
- 영상 마지막 행동(A): "구독·좋아요" 대신 **"영상 속 3천원짜리 매트, 프로필 링크 12번에 있어요"** 처럼 얻는 걸 구체적으로.

## 5. 확인 못 한 것 / 주의

- **핸들 중복 확인 미완료**: 이 작업 환경에서 유튜브·인스타·틱톡 접속이 차단돼 직접 확인하지 못했어요. 2-0 방법으로 가입 전에 확인해 주세요.
