# 🧭 채널 방향 결정 (2026-11-22)

> 오늘 정한 큰 방향이에요. 아래 3~6장의 모든 문서는 이 방향을 기준으로 썼어요.

## 1순위: 아내몰래 꽃미남 피부 (+ 재미)

| 항목 | 내용 |
|---|---|
| 한 줄 정의 | 비누 세수가 전부였던 50대 남편이 아내 몰래 피부 관리를 시작해 "요즘 얼굴 좋아졌네" 소리를 듣는 날까지 가는 성장 시트콤 |
| 만드는 방식 | **직접 촬영** (욕실 거울 앞 폰 거치대 하나). 얼굴 공개가 부담이면 목소리·손·뒷모습만으로도 충분 |
| 재미 포인트 | "들킬까 말까" 긴장감, 허당 남편, 아내의 펀치라인 한마디, 매번 바뀌는 화장품 숨기는 곳 |
| 돈 버는 구조 | 매 편 쓰는 남자 화장품을 쿠팡·올리브영 제휴 링크로 연결 |
| 꼭 지킬 것 | 화장품법: 효능 단정 금지, 증거는 같은 조명·같은 각도 전후 비교 촬영으로만 |
| 대상 | 40~50대 남편 시점으로 시작, 반응 보고 시니어로 확장 |

## 2순위: 인테리어 제휴 숏폼 (업로드만 직접, 나머지 자동화)

| 항목 | 내용 |
|---|---|
| 만드는 방식 | 주제 발굴 → 대본 → 콘티 → 영상 → 목소리 → 편집 → 캡션까지 Claude가 자동으로 |
| 정준님 손 | **대본 검수 5분**(3문장 내 말로 + "직접 해보니" 1문장) + **업로드 5분** |
| 주간 시간 | 주 4편 기준 약 1시간 |
| 제휴 | 쿠팡 파트너스 · 오늘의집 큐레이터 · 네이버 쇼핑 커넥트 · 무촌철거 CPA |
| 꼭 지킬 것 | AI 생성 표시 켜기, 반복·대량생산 콘텐츠로 보이지 않게 형식 돌려쓰기 |

## 시간 배분

- 1순위(촬영 채널)에 시간을 더 쓰고, 2순위는 자동화로 돌려서 손이 덜 가게 해요.
- 두 채널 모두 유튜브 쇼츠 · 인스타 릴스 · 스레드 (+틱톡)에 함께 올려요.
