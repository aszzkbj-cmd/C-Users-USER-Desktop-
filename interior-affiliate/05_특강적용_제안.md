## 2. 패스비아 대본 틀 (04번 6-1 프롬프트 교체안)

### 단계 뜻 (우리 일에 맞춘 버전)

| 단계 | 뜻 | 우리 영상에서는 | 필수? |
|---|---|---|---|
| **P** 문제 | 문제를 먼저 | "현관에 신발 굴러다니죠" | ✅ |
| **E** 공감 | "내 얘기네" | "치워도 이틀이면 또 이래요" ← **제일 중요** | ✅ 꼭 |
| **S** 해결 | 해결법 | 제품·방법 (실제 촬영 컷) | ✅ |
| **B** 이익 | 시청자가 얻는 것 | "3만원으로 현관이 2배 넓어 보여요" | ✅ |
| **E** 증거 | 화면으로 못 보여줄 때만 | 화장품·철거 주장일 때만 (아래 주의) | 필요할 때만 |
| **A** 행동 | 다음을 기대하게 | "다음엔 신발장 없는 집 정리법. 제품은 고정댓글에 👇" | ✅ |

- P와 E는 한 문장에 같이 넣어도 돼요: *"치워도 이틀이면 또 신발 굴러다니는 현관, 저만 그런 거 아니죠?"*
- 팁이 2개면 패스비아를 두 번 돌려도 돼요.

### 새 Claude 프롬프트 (복사용)

```
원룸 인테리어 쇼츠 30초 대본 써줘. 패스비아(PESBEA) 순서로.
주제: (아이디어 목록 문장)
상품: (상품명, 가격)
내 경험: (직접 써보니 어땠는지 한 줄 — 예: 붙이는 데 5분, 3주째 안 떨어짐)

1) P 문제 / E 공감 / S 해결 / B 이익 / E 증거(필요할 때만) / A 행동 칸으로 나눈 장면표
   - E 공감은 시청자가 "내 얘기네" 할 문장으로. 문제 다음 바로 해결로 넘어가지 마.
   - 내 경험 문장을 S나 B에 그대로 넣어줘.
   - 내가 직접 찍을 장면엔 [촬영], AI 보조컷엔 [AI] 표시.
2) A 행동은 "구독·좋아요" 말고, 다음 영상에서 얻을 것 + "제품은 고정댓글에"로.
3) 첫 문장 후보 3개. "원룸 사는 사람"처럼 대상을 좁히지 말고 얻는 이익으로 시작.
4) 설명란 글 + 해시태그 5개.
말투는 앞에 있는 친구한테 말하듯. "상위 1%만 아는" 같은 틀 문장, 과장 표현 빼줘.
```

### 예시: 정수기 30초 대본을 패스비아로 (01번 3번 교체안)

| 단계 | 시간 | 화면 | 내레이션 |
|---|---|---|---|
| P+E | 0–4초 | 생수 들고 계단 오르는 손 **[촬영 1인칭]** | 생수 2묶음 들고 계단 오르다 팔 빠질 뻔한 적, 있으시죠? |
| E | 4–8초 | 현관에 쌓인 빈 페트병 | 마시는 건 금방인데 분리수거는 왜 이렇게 쌓이는지. |
| P | 8–11초 | 계산기 화면 | 계산해 보니 생수만 한 달 2~3만 원이더라고요. *(실제 내 금액으로)* |
| S | 11–19초 | 렌탈형·구매형 정수기 (AI 이미지 2컷) | 렌탈은 관리 포함 월 요금, 구매는 한 번 내고 필터는 직접. |
| B | 19–25초 | 체크리스트 | 2년 이상 살 집이면 렌탈, 곧 이사하면 구매가 덜 아까워요. |
| A | 25–30초 | 폰 빈 화면 (편집에서 글자 합성) | 다음엔 필터 값까지 넣은 1년 비용 비교 보여드릴게요. 내 조건 견적은 프로필 링크에. *(광고)* |

> 기존 대본은 1번 장면 "지치셨죠?"가 공감 역할을 하지만 바로 숫자(해결 근거)로 넘어가요. 공감 한 줄(4–8초)을 더 넣은 게 핵심 차이예요.

### 무촌철거 쇼츠 (03번 4-3) 공감 한 줄 추가안
- 기존: `[0–3초] 가게 문 닫을 때 마지막으로 내는 큰돈, 철거비입니다.` → 바로 `견적서 그대로 믿으면 손해`
- 추가: `[3–6초] 장사 접는 것도 속상한데, 마지막 견적서 보고 한 번 더 놀라시죠.`
- 경험이 없는 캠페인이라 **"제가 맡겨보니"는 여전히 금지**(03번 2-B). 공감은 경험이 아니라 **상황 묘사**로만.

### ⚠️ 증거(E) 넣을 때 주의 (우리 업종 전용)
- 🧴 **화장품:** 특강은 "논문·전문가 인용"을 권하지만, 효능 인용은 **화장품법 위반 위험**("여드름 개선" 등). 증거는 **전성분표 화면, 손등 비교 촬영, 같은 조명 아침/오후 비교**처럼 *눈에 보이는 것*으로만.
- 🔨 **철거:** "25% 저렴"은 **"업체 안내 기준"** 그대로. 증거는 견적 체크리스트·공고 화면(소상공인시장진흥공단) 정도.
- 🏠 **인테리어:** 전·후 촬영이 곧 증거라 보통 생략.

## 3. 경험(IP) 넣기 · AI는 틀만

특강 핵심: *정보는 AI가 다 알려주지만 "직접 해보니"는 AI가 못 한다 → 그게 내 IP.* 강사도 대본을 AI에 통째로 맡기니 조회수가 떨어졌대요.

| 지금 계획 | 바꾸는 점 |
|---|---|
| 04번: AI는 대본·자막·편집 보조, 실촬영 절반 이상 | ✅ 그대로 유지 (특강과 같은 방향) |
| 04번 6-1: Claude 대본 10분 | **20분으로.** 초안에서 **3문장 이상 내 말로 고치기** + **"직접 해보니" 1문장** 필수 |
| 00·01번 정수기 연습세트: AI 그림 7장 + TTS | **연습용으로만.** 실제 업로드본은 최소 **[촬영] 1컷(생수 들기 1인칭) + 내 목소리**로 교체 |
| (없음) | 첫 2개 영상은 **대본을 내가 먼저 쓰고** Claude 초안과 비교 → 어디를 AI에 맡겨도 되는지 감 잡기 |
| (없음) | **말버릇 하나 정하기** (예: "3만원 방꾸, 오늘은 현관"). 얼굴 없이도 말투·관점으로 색깔이 생김. 매번 똑같은 인사말이면 재미있게, 질리면 바꾸기 |

**촬영 장면 고르는 기준(특강):** 시청자가 *흔히 겪어본 장면*을 *1인칭·손이 보이게*. → 우리 목록에선 "생수 들고 계단", "벽지 들뜬 곳 손으로 누르기", "손등에 선크림 문지르기"가 딱 맞아요. 마음에 안 들면 3~4번 다시 찍기.

## 4. 주제 찾는 법 (04번 '월요일 주제 정하기'에 추가)

> 머리로 짜내지 말고 **이미 잘된 주제**를 가져와 **내 경험 + 댓글 한 마디**로 업그레이드. 내용 그대로 베끼기는 금지.

매주 월요일 19:00~19:40 (40분)
- ☐ 1. **아웃라이어 찾기:** 유튜브에서 `자취방 꾸미기` `원룸 정리` `무타공` / `남자 스킨케어` `남자 선크림` 검색 → **구독자 수보다 조회수가 10배 넘는 영상**을 최신순으로 5개 메모
  - 유튜브 스튜디오 → 인사이트(조사) 탭에 아웃라이어 점수가 보이면 그걸 쓰기. 새 채널이라 안 보이면 위처럼 검색으로.
- ☐ 2. **댓글 캐기:** 그 영상들의 **좋아요 많은 댓글 3개씩** 복사 → 원본이 답 안 한 질문 찾기 (예: "월세방도 돼요?", "지성도 써도 돼요?") → 그 한 마디를 내 영상 S 또는 B에 넣기
- ☐ 3. **일본 레퍼런스:** `一人暮らし 収納` `100均 インテリア` `メンズスキンケア` 검색 → 국내에 없는 디테일 1개. 특히 **100균 → 다이소·쿠팡 같은 물건**으로 바꾸면 제휴 링크까지 연결돼요
- ☐ 4. **탐색용 계정 (1주차에 1번만):** 새 인스타·유튜브 계정에 관련 채널 50~100개 구독/팔로우 → 잘된 영상만 뜨게. 저장 폴더는 `인테리어` `화장품` `철거·폐업` 3개
- ☐ 5. 고른 4개를 2번 패스비아 프롬프트에 넣기
- ☐ 6. (선택) 유튜브 스튜디오 **'물어보기'** 기능이 보이면: `최근 영상 5개랑 한국에서 지금 인기 있는 주제 기준으로 영상 주제 추천해줘`

**3주차 22~24번 보완:** "잘 된 영상 형식 3번 따라 하기" 전에, **왜 잘 됐는지 한 줄**(첫 문장? 공감 장면? 댓글에서 뭐라고 했나?)을 먼저 적기. 내 영상을 인기순으로 놓고 **잘 먹히는 주제·길이(치트키)** 찾기. 길이는 필요한 만큼만 — 30초면 30초.

## 5. 대상 넓히기 (훅 문장 교체안)

특강 피드백 대부분이 "처음부터 대상을 좁히지 마라, **얻는 이익**으로 넓혀라"였어요.

| 지금 (04번 5번 / 01번) | 바꾸면 |
|---|---|
| 원룸 현관, 3만원이면 이렇게 바뀝니다 | **현관 넓어 보이고 싶으면, 3만원이면 돼요** (화면에 원룸이 보이니 말로 안 좁혀도 됨) |
| 월세방 벽에 못 안 박고 선반 다는 법 | **벽에 구멍 하나 없이 선반 다는 법** (월세·자가 모두) |
| 원룸 사는데 생수 들고 올라오기 지치셨죠? | **생수 들고 계단 오르다 팔 빠질 뻔한 적 있죠?** |
| 화장품 하나도 모르는 남자의 첫 스킨케어 | ✅ 그대로 OK (이미 "초보 누구나"로 넓음) |
| 번들거리는 남자 이마, 오후 3시 비교 | **오후 3시만 되면 얼굴 번들거리는 분** (남녀 다 공감) |

- **계정 이름:** 2번 표 중 **"3만원 방꾸"**가 이익 중심이라 특강 기준에 제일 맞아요. "원룸 고치는 남자"는 대상이 좁아 보일 수 있어요. 화장품은 "세안부터 다시"가 넓고, "정준의 파우치"는 사람 중심이라 IP엔 유리해요.
- **제품부터 내세우지 않기:** 특강 "제품부터 내세우면 광고 채널로 찍힌다". → 상품명은 S 단계에서, 첫 문장엔 넣지 않기.

## 6. 힉스필드 콘티에 PESBEA 붙이기 (크레딧 절약 원칙과 연결)

콘티(원칙 1) 단계에서 컷마다 **P·E·S·B·E·A 라벨**을 붙이면, 어떤 컷에 크레딧을 쓸지 바로 정해져요.

| 라벨 | 만드는 법 | 크레딧 |
|---|---|---|
| **E 공감 컷** (사람이 겪는 장면) | 가능하면 **직접 촬영**. 못 찍으면 Seedance Mini 480p 테스트 → 통과 시 Kling 3초 | 0 ~ 약 7 |
| **P·S·B 정보 컷** (제품·숫자·체크리스트) | 이미지만 + 편집에서 줌·패닝 (원칙 3) | 0.5~1 |
| **A 마무리 컷** (폰·링크 안내) | 빈 화면 이미지 + 편집에서 글자 합성 (원칙 6) | 0.5 |

- 실촬영 비중이 늘수록 AI 영상 컷은 **영상당 1~2개**로 줄어서 목표(편당 40크레딧 이하)보다 훨씬 적게 들 거예요.
