## 3. 힉스필드 크레딧 계획 (편당 40크레딧 이하)

인테리어는 **소품·공간 컷이 대부분**이라 이미지 + 줌으로 처리하고, 사람 움직임 컷 1~2개만 영상으로 만들어요.

| 항목 | 모델 | 개수 | 대략 크레딧 |
|---|---|---|---|
| 콘티 이미지 | 무제한 모델 (없으면 GPT Image 2 low) | 6~7장 | 0~7 |
| 최종 확정 이미지 | Nano Banana Pro (최종 컷만) | 3~4장 | 생성 전 `견적 확인` 후 진행 |
| 움직임 테스트 | Seedance 2.0 Mini 480p | 2클립 | 약 5 |
| 최종 영상 | Kling, **3초** | 2클립 | 약 9 |
| 목소리 | 정준님 목소리 클론 | 30~40초 | 생성 전 견적 확인 |
| **합계 목표** | | | **약 25~35** |

지키는 것:
- 영상 **오디오 끄고** 생성 (소리는 편집에서)
- 한글 글자(가격표·체크리스트 등)는 **빈 화면으로 생성 → 편집에서 합성**
- 반복 장면(원룸 전경, 현관, 주방, 손 클로즈업)은 **장면 라이브러리**에 저장해 재사용
- 인물이 나오면 **캐릭터 시트 1장**으로 고정 (손만 나오는 컷 위주라 대부분 불필요)
- 생성 전 매번 견적 확인 → 편당 40 넘으면 영상 컷을 이미지+줌으로 바꿈

### 6-1. 유튜브 쇼츠 (약 35초)

**제목:** 벽에 구멍 하나 없이 선반 다는 법 (월세방 OK)

|---|---|---|---|---|
| 1 | P 문제 (0~3초) | 텅 빈 벽 앞에 물건이 바닥에 쌓인 원룸 구석 · 🖼️ 이미지 + 천천히 줌인 | "벽에 구멍 하나 없이 선반 달고 싶으면, 이거 보세요." | 구멍 0개로 선반 달기 |
| 2 | P 문제 (3~7초) | 화장품·충전기·향초가 책상 위에 뒤엉킨 모습 · 🖼️ 이미지 + 패닝 | "올려둘 데가 없으니까 책상이 전부 창고가 되잖아요." | 책상 = 창고 |

| 5 | 🟨 직접 해보니 (20~25초) | 선반 위에 물건 정리된 모습 · 🖼️ 이미지 + 줌아웃 | 🟨 "제가 직접 해보니 ________________" *(예: 붙이고 하루 지나서 올려야 덜 떨어지더라고요)* | 🟨 |
| 6 | B 이익 (25~30초) | 전 / 후 나란히 (왼쪽 지저분, 오른쪽 정리) · 🖼️ 2장 합성 | "□만원 정도로 책상이 비고, 방이 한 뼘 넓어 보여요." | 전 → 후 |
| 7 | A 행동 (30~35초) | 선반 클로즈업 + 빈 폰 화면 · 🖼️ (글자는 편집 합성) | "제가 고른 기준이랑 버티는 무게까지 고정댓글에 정리해 뒀어요. 다음 편은 못 안 박고 거울 거는 법이에요." | 상품·기준 👉 고정댓글 |

### 6-3. 스레드 (글 중심, 3개 이어 쓰기)

스레드는 영상보다 **대화하는 글**이 잘 돼요. 사진 1장(6번 전·후 컷) + 이어지는 글 3개.

**글 1 (사진 첨부)**
```
[광고] 제휴 링크 포함

월세방에서 선반 달고 싶은데 보증금 때문에 못 박으신 분?
구멍 하나 없이 달아봤어요. 전후 어때요?
```

**글 2**
```
고를 때 이 3개만 보면 돼요.
1. 버티는 무게 표시가 있는지
2. 우리 집 벽지에 맞는 고정 방식인지 (실크벽지면 특히 확인)
3. 뗄 때 자국 안내가 있는지
```

**글 3**
```
🟨 직접 해보니 제일 중요한 건 ________ 였어요.
(예: 붙이고 바로 올리면 안 되고 하루 기다려야 해요)

제가 쓴 건 프로필 링크에 있어요.
다음엔 못 안 박고 전신거울 거는 법 올릴게요. 궁금한 거 있으면 댓글로!
```

### 6-4. 이 대본 자동 검사 결과

| 항목 | 결과 |
|---|---|
| 훅이 이익으로 시작 | ✅ "벽에 구멍 하나 없이 선반 달고 싶으면" |
| 공감 한 줄 | ✅ 3번 "보증금 깎일까 봐 손이 멈추죠" |
| 직접 해보니 | 🟨 정준님 채울 곳 (5번 컷, 스레드 글 3) |
| 구독·좋아요 없음 | ✅ 다음 편 예고 + 고정댓글 안내 |
| 과장 표현 | ✅ "자국이 거의 안 남는 제품이 많아요"처럼 단정하지 않음 |
| 광고 표기 | ✅ 첫 화면, 설명 첫 줄, 캡션 첫 줄, 스레드 첫 글 |
| 영상 컷 | ✅ 사람 움직임 컷(3·4번)만 영상, 나머지 이미지+줌 |
