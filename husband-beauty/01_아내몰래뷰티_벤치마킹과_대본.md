## 2. 우리 채널 방향

### 캐릭터
- **나(남편):** 허당, 쑥스러움 많음, 하지만 진지하게 "작전"을 짠다. 007 흉내 내는 50대.
- **아내:** 화면엔 거의 안 나오고 목소리나 손만. 결말에 한마디로 다 무너뜨리는 사람.

### 매 편 고정 포맷 (이게 시리즈를 기억하게 만든다)
1. **오프닝 고정 멘트:** "아내몰래 꽃미남 프로젝트, D+○일. 아직 안 들켰습니다."
2. **작전 브리핑:** 오늘 몰래 할 것(세안, 선크림, 눈썹 정리, 팩 등)
3. **숨기기:** 화장품 숨기는 장소가 매번 바뀜(공구함, 낚시 가방, 차 트렁크, 양말 서랍) ← 고정 웃음 포인트
4. **들킬 뻔한 순간:** 문 여는 소리, 아내 발소리 → 급하게 숨기기
5. **결말 한 줄:** 아내의 펀치라인
6. **들킴 카운터:** 화면 구석에 "아내 눈치 레이더 ■■□□□" 게이지 (편집으로 넣기)

### 시리즈가 오래 가는 소재 목록
- 꽃미남 피부 편(메인): 세안 → 선크림 → 팩 → 눈썹 → 입술 → 손 관리
- 곁가지 편: 아내몰래 복근 프로젝트, 아내몰래 아내 친구 만나 선물 고르기, 아내몰래 옷장 정리
- 이벤트 편: 결혼기념일에 "사실 나 3개월째 관리했어" 공개(시즌 피날레)

### 지켜야 할 규칙
- **화장품법:** "주름 개선", "미백 효과", "피부 재생" 같은 효능 단정 말 금지. "써 보니 아침에 덜 땅긴다" 같은 **내 느낌**까지만 말하고, 나머지는 비교 화면으로 보여 주기.
- **광고 표시:** 제휴 링크가 있으면 영상에 "유료 광고 포함" 표시를 켜고, 설명란에 쿠팡 파트너스 문구를 넣는다.
  > "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- **전후 비교 촬영 규칙:** 같은 장소(욕실 거울 앞), 같은 시간대, 같은 조명, 같은 각도, 보정 필터 없음.

| 10~12초 | 반전 | 아내 손이 크림을 낚아챔 | "내 크림 왜 반이나 없어?" |
| 12~22초 | 해결 | 공구함 열기 → 3개 하나씩 | 남편용은 딱 3개 ① 세안제 ② 올인원 ③ 선크림 / 숨기는 곳: 공구함 |
| 22~26초 | 이익 | 5분 타이머 | 아침 5분 + 집안 평화 지킴 |
| 26~30초 | 행동 + 결말 | 공구함 위 아내 손 | **저장해 두면 마트에서 바로 꺼내 보세요** / 프로필 링크에 3개 정리 / "…이거 뭐야?" |

**캡션**
> 피부 관리라고는 비누 세수가 전부였던 남편, 아내 크림 몰래 쓰다가 결국 걸렸습니다.
> [직접 해보니 느낀 점 한 줄: 정준님 말로]
> 그래서 제 거 딱 세 개만 샀어요. 저장해 두면 마트에서 헤매지 않아요. 제품은 프로필 링크에 가격까지 정리해 뒀습니다.
> 2주 뒤 같은 조명으로 전후 비교 올릴게요. 들켰는지도요.
>
> #아내몰래 #남편스킨케어 #50대남자 #남자화장품 #부부일상 #아저씨피부관리 #남자기초화장품

## 4. 2순위 인테리어: "업로드만 직접, 나머지 전부 자동화" 어떤가요?

**좋다고 봐요. 다만 사람 손이 꼭 들어가야 할 곳이 두 군데 더 있어요.**

| 단계 | 자동화 | 정준님 손 |
|---|---|---|
| 주제 수집 (구독자 대비 10배 영상, 일본 영상) | ✅ 매주 월요일 자동으로 후보 10개 | |
| 대본 초안 (패스비아) | ✅ Claude 초안 | **✋ 3문장 고치고 경험 한 줄 넣기 (5분)** |
| 콘티 이미지 | ✅ 무제한 모델 / GPT Image 2 low | |
| 영상 (움직이는 컷만) | ✅ Seedance 테스트 → Kling 최종 | |
| 자막·한글 합성·제휴 링크·캡션 | ✅ 플랫폼별 자동 | |
| 최종 검수 + 업로드 | | **✋ 한 번 보고 올리기** |

**왜 두 군데는 손으로?**
- 특강에서 AI에 통째로 맡기면 조회수가 떨어진다고 했고, 플랫폼도 비슷한 AI 영상이 반복되면 노출을 줄이는 쪽으로 가고 있어요. 경험 한 줄이 그걸 막아 줘요.
- 업로드를 직접 하시는 건 오히려 좋은 선택이에요. 올리기 직전에 링크·광고 표시·글자 깨짐을 한 번 보게 되니까요.

**예상 시간:** 한 편당 정준님 손은 약 10~15분(대본 수정 5분 + 검수·업로드 10분). 1순위 촬영 채널에 시간을 더 쓰실 수 있어요.

**다음 단계 제안:** 원하시면 이 자동화 흐름을 무촌철거 CPA 캠페인에 맞춰 실제 단계별 설정(어떤 툴, 어떤 순서)으로 짜 드릴게요.
